# Репетитор Аянокоджи

Сайт-репетитор по школьным предметам для 8–11 класса. Объясняют Аянокоджи Киётака и Амасава Ичика — по одному или вместе.

**Сайт:** https://ayanokoji-tutor.vercel.app (основной, со входом) · копия без входа: https://welixx387.github.io/ayanokoji-tutor/

## Что внутри

- 12 курсов, 213 уроков: алгебра, геометрия, физика, химия, биология, география, информатика, русский язык, литература, история, обществознание, английский язык.
- В каждом уроке — теория с таблицами и примерами, задачи с решениями, тест и конспект; в конце курса — экзамен.
- Раздел IQ: 5 уровней сложности, бесконечная генерация заданий и тест с примерной оценкой IQ.
- Очки PP и классы D → A, тёмная и светлая тема, поиск по урокам.

- Аккаунты: регистрация и вход по нику или email с паролем, прогресс сохраняется в облаке, общий рейтинг OAA.

Где работает вход:

| Версия | Вход | Прогресс |
|---|---|---|
| Vercel | ник или email + пароль (свой API в `api/`, база Neon Postgres) | в аккаунте |
| Claude (артефакт) | аккаунт Claude | в аккаунте |
| GitHub Pages | нет — статическая копия | в браузере |

## Структура

```
index.html          разметка и стили (фрагмент страницы без <html>/<body>)
app.js              движок: маршруты, уроки, тесты, экзамены, прогресс
iq.js               раздел IQ: генераторы заданий и тест
data/subjects.js    список предметов и уроков
data/<предмет>/NN.js  содержимое уроков
img/                изображения репетиторов
api/[action].js     API аккаунтов: register, login, logout, me, save, board, profile, password, delete
api/_lib/           база (Neon Postgres, таблицы создаются сами) и пароли/сессии
scripts/build-pages.sh  сборка статической части в _site/
```

Пароли хранятся как хэш scrypt, сессия — в cookie `HttpOnly; Secure; SameSite=Lax`, токен сессии в базе хранится только как SHA-256. Есть защита от подбора пароля (блокировка аккаунта на 10 минут после 8 ошибок) и лимиты запросов по IP.

## Публикация

- **Vercel:** `vercel deploy --prod --yes` из папки проекта. Нужна переменная окружения `DATABASE_URL` — её добавляет интеграция Neon.
- **GitHub Pages:** каждый push в ветку `main` запускает workflow `.github/workflows/pages.yml`, который собирает и публикует статическую копию.

Локальная проверка:

```sh
sh scripts/build-pages.sh
npx serve _site
```
