# Репетитор Аянокоджи

Сайт-репетитор по школьным предметам для 8–11 класса. Объясняют Аянокоджи Киётака и Амасава Ичика — по одному или вместе.

**Сайт:** https://welixx387.github.io/ayanokoji-tutor/

## Что внутри

- 12 курсов, 213 уроков: алгебра, геометрия, физика, химия, биология, география, информатика, русский язык, литература, история, обществознание, английский язык.
- В каждом уроке — теория с таблицами и примерами, задачи с решениями, тест и конспект; в конце курса — экзамен.
- Раздел IQ: 5 уровней сложности, бесконечная генерация заданий и тест с примерной оценкой IQ.
- Очки PP и классы D → A, тёмная и светлая тема, поиск по урокам.

На GitHub Pages прогресс хранится в браузере. Вход через аккаунт, облачная синхронизация и общий рейтинг работают только в версии сайта, опубликованной в Claude.

## Структура

```
index.html          разметка и стили (фрагмент страницы без <html>/<body>)
app.js              движок: маршруты, уроки, тесты, экзамены, прогресс
iq.js               раздел IQ: генераторы заданий и тест
data/subjects.js    список предметов и уроков
data/<предмет>/NN.js  содержимое уроков
img/                изображения репетиторов
scripts/build-pages.sh  сборка версии для GitHub Pages в _site/
```

## Публикация

Каждый push в ветку `main` запускает workflow `.github/workflows/pages.yml`: он собирает сайт скриптом `scripts/build-pages.sh` и публикует его на GitHub Pages.

Локальная проверка:

```sh
sh scripts/build-pages.sh
npx serve _site
```
